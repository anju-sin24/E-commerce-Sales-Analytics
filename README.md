🛍️ ShopNest E-Commerce Sales Dashboard | Power BI

1. Project Overview -
ShopNest is an interactive Power BI dashboard created to analyze e-commerce sales, orders, customer ratings, payment methods, and delivery performance.
The dashboard provides a clear view of overall business performance and helps identify sales trends, top-performing categories, delayed orders, customer ratings, and state-wise sales performance.

2. Business Problem -
E-commerce businesses generate large amounts of sales and order data, making it difficult to understand overall performance through raw data.
The objective of this project is to transform the data into an interactive dashboard that helps users quickly monitor:

* Revenue and total orders
* Sales performance by category and state
* Delayed vs. on-time orders
* Customer ratings
* Payment method distribution
* Seasonal and yearly sales trends

3. Goal of the Dashboard -
The main goal is to provide an interactive business intelligence dashboard that helps analyze sales and operational performance.
The dashboard allows users to filter the analysis by:

* State
* Year
* Order Status
and explore different aspects of e-commerce performance.

4. Tools & Technologies -

* 📊 Power BI Desktop – Dashboard creation and data visualization
* 🔄 Power Query – Data cleaning and transformation
* 🧮 DAX – Calculated measures and business calculations
* 🗂️ Data Modeling – Creating relationships between tables
* 📁 File Formats – .pbix for Power BI development and .png for dashboard preview

5. Data Source -
Source: Excel files containing e-commerce sales and order data.
The datasets include information related to orders, products, sales, customers, payment methods, ratings, delivery status, and customer locations. The data was cleaned and transformed using Power Query before creating the dashboard in Power BI.

7. Key Insights -

* Overall revenue and order performance
